Association Jigi

Demo project

Donation tracking application for a nonprofit.

A single-page web application (React, Bootstrap, and a Laravel API) to record donations, track how they are used and redistributed, and let each donor follow their own contributions.

Client:
Association Jigi (fictional).
Industry:
Nonprofit and community support.
Year:
2026.
Duration:
3 mois.
Roles:
UX/UI design and visual identity, project requirements, front-end and back-end development, testing, and documentation.
Technologies:
React, TypeScript, Bootstrap 5, Vite, Laravel, PHP, MySQL, Vitest, React Testing Library.

Context

A nonprofit receives donations from different sources (individuals, businesses, and partners), sometimes in CFA francs, US dollars, and euros. It uses some funds for its programs and redistributes others to beneficiaries. Without a single tool, these transactions are hard to track and account for. Association Jigi is a fictional organization designed to address this need: record every donation, track how it is used, and reassure donors. Its name evokes hope in Bambara. It is also a NexaWeb Mali demo project: a React application with a Laravel API, a visual identity created for the association, and fictional data only.

Challenges

A tool designed for mobile first: donation entry in under a minute, lightweight pages (under 3 seconds on 4G), and an accessible interface (WCAG 2.1 AA).

Three currencies, kept separate: CFA francs, US dollars, and euros, with totals always shown per currency and never combined.

Reliable balances: available balance equals donations received minus expenditures; pledged or cancelled donations are excluded, and spending above the balance is rejected.

Access tailored to each role: administrator, manager, viewer, and donor, with donors able to see only their own contributions.

Solutions

React and strict TypeScript: a single-page application built with Vite, hash routing for GitHub Pages, shared state with React Context, and validated forms (React Hook Form and Zod).

Laravel API and MySQL: REST API in JSON, token authentication (Sanctum), role-based permissions (Policies), validation with Form Requests, and demo data from seeders.

Server-side business rules: amounts stored as integers in each currency's smallest unit, balances calculated per currency, and expenditures checked before being saved.

Bootstrap 5 interface in the association's colors: logo, palette (terracotta, dark brown, sunshine yellow, and green), verified contrast, keyboard navigation, and accessible tables.

Quality and design: 13-section project specification, mockups for 23 screens (desktop and mobile), automated tests (Vitest, React Testing Library, and API tests), and atomic commits.

Results

  • A custom visual identity (a rising-sun "j" logo, brand guidelines, and AA contrast) and a complete 13-section project specification
  • Mockups for 23 desktop and mobile screens across all four user roles
  • End-to-end tracking of donations, expenditures, and redistribution, with a per-currency dashboard, campaigns, and CSV exports
