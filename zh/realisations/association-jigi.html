Jigi 协会

演示项目

为协会打造的捐赠追踪应用。

单页 Web 应用（React、Bootstrap 和 Laravel API），用于登记收到的捐赠、追踪其使用和再分配情况，并让每位捐赠者查看自己的捐赠记录。

客户：
Jigi 协会（虚构项目）。
行业：
协会与公益。
年份：
2026 年。
周期：
3 个月。
职责：
UX/UI 设计和视觉形象、需求规格、前后端开发、测试和文档编写。
技术：
React、TypeScript、Bootstrap 5、Vite、Laravel、PHP、MySQL、Vitest、React Testing Library。

项目背景

协会收到来自个人、企业和合作伙伴等不同来源的捐赠，币种可能包括西非法郎、美元和欧元。部分资金用于开展活动，另一部分则分配给受益人。如果没有统一工具，这些资金流向很难追踪和说明。Jigi 协会是为满足这一需求而设立的虚构协会：登记每笔捐赠、追踪资金去向并让捐赠者安心。其名称在班巴拉语中寓意希望。这也是 NexaWeb Mali 的演示项目：采用 React 和 Laravel API 的应用，拥有协会专属视觉形象，且仅使用虚构数据。

挑战

优先为手机设计的工具： 一分钟内即可录入捐赠，页面轻巧（4G 网络下加载少于 3 秒），界面符合无障碍标准（WCAG 2.1 AA）。

三种货币，清晰区分： 西非法郎、美元和欧元的总额始终按币种分别计算，绝不混加。

准确可靠的余额： 可用余额 = 已收到的捐赠减去已使用的金额；不计入承诺捐赠或已取消的捐赠，并拒绝超出余额的支出。

根据用户角色设置访问权限： 管理员、管理者、只读用户和捐赠者；捐赠者只能查看自己的捐赠记录。

解决方案

React 与严格 TypeScript： 使用 Vite 构建的单页应用，通过哈希路由适配 GitHub Pages，使用 React Context 共享状态，并通过 React Hook Form 和 Zod 验证表单。

Laravel API 与 MySQL： JSON 格式的 REST API、基于令牌的身份验证（Sanctum）、按角色授权（Policies）、通过 Form Request 验证，以及由 Seeder 生成的演示数据。

服务器端业务规则： 金额以各币种最小单位的整数存储，按币种计算余额，并在保存前核查支出。

采用协会配色的 Bootstrap 5 界面： 徽标、配色（陶土色、深棕色、明黄色、绿色）和经过验证的对比度，并支持键盘导航和无障碍表格。

质量与设计： 包含 13 个部分的需求规格、23 个界面原型（桌面版和手机版）、自动化测试（Vitest、React Testing Library 和 API 测试），以及原子化提交。

成果

  • 定制视觉形象（旭日中的“j”徽标、品牌规范和符合 AA 级的对比度），以及完整的 13 部分需求规格。
  • 针对四种用户角色设计的 23 个界面原型，包含桌面版和手机版。
  • 完整追踪捐赠、使用和再分配情况，并提供按币种划分的仪表板、活动管理和 CSV 导出。
  • 仅供只读访问的捐赠者中心，每位捐赠者只能查看自己的捐赠记录。
