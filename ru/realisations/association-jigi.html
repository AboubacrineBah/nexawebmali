Association Jigi

Демонстрационный проект

Приложение для учёта пожертвований ассоциации.

Одностраничное веб-приложение (React, Bootstrap и API Laravel) для регистрации пожертвований, отслеживания их использования и распределения, а также просмотра каждым жертвователем собственных взносов.

Клиент:
Association Jigi (вымышленный проект).
Отрасль:
Общественная деятельность и взаимопомощь.
Год:
2026.
Срок:
3 месяца.
Роль:
Проектирование UX/UI и фирменного стиля, техническое задание, frontend- и backend-разработка, тестирование, документация.
Технологии:
React, TypeScript, Bootstrap 5, Vite, Laravel, PHP, MySQL, Vitest, React Testing Library.

Контекст

Ассоциация получает пожертвования из разных источников (от частных лиц, компаний и партнёров), иногда в CFA, долларах США и евро. Часть средств идёт на её деятельность, другая распределяется между нуждающимися. Без единого инструмента отслеживать и подтверждать движение средств сложно. Вымышленная Association Jigi решает эту задачу: регистрирует каждое пожертвование, отслеживает его использование и укрепляет доверие жертвователей. Её название означает «надежда» на языке бамбара. Это также демонстрационный проект NexaWeb Mali: приложение на React с API Laravel, фирменным стилем ассоциации и исключительно вымышленными данными.

Задачи

Инструмент, прежде всего рассчитанный на мобильные устройства: Регистрация пожертвования менее чем за минуту, лёгкие страницы (загрузка менее чем за 3 секунды в сети 4G) и доступный интерфейс (WCAG 2.1 AA).

Три валюты без путаницы: CFA, доллар США и евро; итоги всегда отображаются отдельно по каждой валюте и не суммируются.

Надёжные остатки: Доступный остаток равен полученным пожертвованиям за вычетом расходов; обещанные и отменённые пожертвования не учитываются, а расходы сверх остатка запрещены.

Права доступа для каждой роли: Администратор, менеджер, наблюдатель и жертвователь; последний видит только собственные пожертвования.

Решения

React и TypeScript в строгом режиме: Одностраничное приложение на Vite, маршрутизация по hash для GitHub Pages, общее состояние через React Context и формы с проверкой данных (React Hook Form и Zod).

API на Laravel и MySQL: REST API в формате JSON, аутентификация по токенам (Sanctum), права по ролям (Policies), проверка данных через Form Requests и демонстрационные данные через сидеры.

Бизнес-правила на стороне сервера: Суммы хранятся целыми числами в минимальных единицах каждой валюты; остаток рассчитывается отдельно по валютам, а расходы проверяются до сохранения.

Интерфейс на Bootstrap 5 в цветах ассоциации: Логотип, палитра (терракотовый, тёмно-коричневый, солнечно-жёлтый и зелёный), проверенные контрастность, навигация с клавиатуры и доступные таблицы.

Качество и проектирование: Техническое задание из 13 разделов, макеты 23 экранов для компьютера и телефона, автоматизированные тесты (Vitest, React Testing Library и тесты API) и атомарные коммиты.

Результаты

  • Индивидуальный фирменный стиль (логотип «j» на фоне восходящего солнца, руководство по стилю и контрастность уровня AA) и полное техническое задание из 13 разделов
  • Макеты 23 экранов для компьютера и телефона, рассчитанные на четыре роли пользователей
  • Полный учёт пожертвований, расходов и распределений, панель управления по валютам, кампании и экспорт в CSV
  • Личный кабинет жертвователя только для чтения, с доступом исключительно к его пожертвованиям
