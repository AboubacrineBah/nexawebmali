Association Jigi

Jira porozɛ

Jɛkulu ye don ɲɛtaa aplikasyon.

Web aplikasyon kelen-page (React, Bootstrap ni Laravel API) walasa ka donw sɛbɛn, ka u baara ni bɔcogo lajɛ, ani ka donbaga kelen-kelen se k’a yɛrɛ ka donw lajɛ.

Klient:
Association Jigi (fɛn-fɔlɔ).
Baara sektor:
Jɛkulu ni dɛmɛbaara.
San:
2026.
Janya:
Kalo saba.
Baara:
UX/UI jɔli ni jɛɲɛgɛnw, porozɛ kunnafoni sɛbɛn, front-end ni back-end jɔli, testw, sɛbɛnni.
Teknolojiyɛ:
React, TypeScript, Bootstrap 5, Vite, Laravel, PHP, MySQL, Vitest, React Testing Library.

Sɛbɛnni

Jɛkulu bɛ donw sɔrɔ yɔrɔ caman na (mɔgɔw, baarakɛlaw, dɛmɛlaw), dɔrɔn FCFA la, dɔw US dollar ni euro la. Jɛkulu bɛ dɔw baara kɛ a ka baaraw ye, dɔw fana bɛ di baarakɛlaw ma. Ni baarakɛfɛn kelen tɛ, taama inw ɲɛtaa ni olu kunnafoni fɔ gɛlɛn. Association Jigi ye jɛkulu fɛn-fɔlɔ ye min bɛ o ɲinini jaabi: don kelen-kelen sɛbɛn, a ka kɛcogo lajɛ, ani donbagaw dusu hɛrɛya. A tɔgɔ bɛ jigiya fɔ Bamanankan na. O ye NexaWeb Mali ka jira porozɛ fana ye: React aplikasyon ni Laravel API, jɛkulu yɛrɛ ka jɛɲɛgɛnw, ani kunnafoni fɛn-fɔlɔw dɔrɔn.

Gɛlɛya

Baarakɛfɛn min daminɛra telefɔni kosɔn: Don sɛbɛnni min tɛ miniti kelen bɔ, page nafolo dɔgɔw (sekɔndi 3 kɔrɔ 4G la), ani interface min bɛ se ka don (WCAG 2.1 AA).

Wari cogo saba, ka kɛkow ɲɛ: FCFA, US dollar ni euro; totalw bɛ bɔ kelen-kelen wari cogo la, u tɛ fara ɲɔgɔn kan.

Bari ɲuman: Wari min bɛ yen = don sɔrɔlenw ni baaraw bɔlen; don jiginna walima bɔra tɛ lajɛ; baarakɛ min bɛ tɛmɛ wari yenna, a tɛ sɔn.

Donni hakɛw ni mɔgɔ kelen-kelen ka fɛn: Admin, ɲɛnabɔla, kalanbaga ni donbaga; donbaga bɛ a yɛrɛ ka donw dɔrɔn lajɛ.

Ɲɛnabɔliw

React ni TypeScript strict: Aplikasyon kelen-page Vite ye jɔra, hash cogo ye GitHub Pages taamali, React Context ye state dɔgɔw ɲɔgɔn di, ani formu sɛgɛsɛgɛra (React Hook Form ni Zod).

Laravel API ni MySQL: API REST JSON la, tokenw ye donni sɛgɛsɛgɛ (Sanctum), hakɛw porofil kelen-kelen (Policies), Form Requests ye sɛgɛsɛgɛ, seeders ye kunnafoni jira.

Baara sariyaw server fan: Wari hakɛ bɛ mara integer ye wari kelen-kelen ka fitini cogo la, bari sɛgɛsɛgɛ wari kelen-kelen, baarakɛ lajɛ walasa k’a sɛbɛn.

Bootstrap 5 interface jɛkulu ka jɛɲɛgɛnw ye: Logo, jɛɲɛgɛnw (terracotta, dusu finman, tilelen, wɛrɛ), contrastw sɛgɛsɛgɛra, keyboard taamali ni tablow sekoɲɔgɔnyalen.

Kɛcogo ɲuman ni jɔli: Porozɛ kunnafoni sɛbɛn kɔnɔfɔ 13, maquette ekiran 23 (ordinatɛri ni telefɔni cogo), test automatiques (Vitest, React Testing Library ni API testw), ani commits kelen-kelen.

Nafolo ɲɛtaa

  • Jɛɲɛgɛnw yɛrɛ ta (logo “j” tile bɔli la, sariyaw ni AA contrastw) ani porozɛ kunnafoni sɛbɛn dafalen, kɔnɔfɔ 13 ye.
  • Ekirani maquette 23, ordinatɛri ni telefɔni cogo la, baarakɛlaw porofil naani ye.
  • Donw, baara ni bɔcogo ɲɛtaa dafalen, wari cogo kelen-kelen ka dashboard, campagnew ni CSV bɔli.
  • Donbaga yɔrɔ kalan dɔrɔn, a ka donw dɔrɔn lajɛ.
  • [N] tables, [N] controllers ni [N] test automatiques: [jɔli kɔfɛ ka kunnafoni fara a kan]
  • Loading waati, Lighthouse scores ni test laban: olu bɛna sɛgɛsɛgɛ porozɛ sigi kɔfɛ.
